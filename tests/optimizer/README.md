# Differentiable electron-lifetime fit studies

Validate tred's differentiable simulation by fitting the electron lifetime
τ with gradient descent: Adam minimizes the MSE between simulated waveforms
and a noisy "truth" generated by the same simulation chain
(`src/tred/plots/graph_opt.py`, invoked as `tred -c <config> train -i <hdf5>`).

## Method

- **Truth**: one forward pass at the nominal lifetime plus frozen Gaussian
  noise per tick — drawn once from a seeded CPU generator (`noise_seed`,
  `noise_rms`) and added to the truth only. The prediction stays noiseless,
  so the objective is deterministic: repeated evaluations are bit-identical
  and runs are exactly resumable (same seed → same objective).
- **Fit**: two independent arms start above and below nominal
  (`lifetime_inc`/`lifetime_dec` × `lifetime`). With the deterministic
  objective both arms converge to the same minimum at the ns level.
- **Statistics**: the frozen noise ε displaces the loss minimum by
  δτ = ⟨ε, ∂f/∂τ⟩ / ‖∂f/∂τ‖², a zero-mean draw with
  σ_τ = σ_noise / ‖∂f/∂τ‖ (Fisher bound). The offset from nominal scales
  ~linearly with the noise level and shrinks with total charge and with the
  drift-time lever arm (∂f/∂τ = f·t_drift/τ²) — long-drift charge carries
  the lifetime information.

Config keys read by `graph_opt.py` (all optional, defaults in the module):
`lifetime` (ms), `event_list`, `tpc_id`, `lifetime_inc`, `lifetime_dec`,
`nepoches`, `nepoches_inc`/`nepoches_dec` (per-arm override, e.g. to extend
one arm), `lr` (µs per Adam step), `nbchunk` (segments per forward chunk),
`noise_rms` (e−/tick), `noise_seed`.

## Studies

All with nominal τ = 1.0 ms.

| directory | input | drift times | σ (e−/tick) | starts (ms) | fitted τ (ms) | offset |
|---|---|---|---|---|---|---|
| `.` (stress) | ev2 TPC2, 6 segments, 0.6 MeV | 21–83 µs | 170 | 1.24 / 0.87 | 0.97379 | −26 µs (σ_τ ≈ 110 µs) |
| `muon_long_track/` | ev10 TPC1 muon, 38 segments, 67 MeV | 5–184 µs | 170 | 1.2 / 0.8 | 0.99925 | −0.75 µs |
| `muon_widestart_500/` | same muon | same | 500 | 2.0 / 0.5 | 0.99823 | −1.8 µs |
| `muon_widestart_170/` | same muon | same | 170 | 2.0 / 0.5 | 0.99925 | −0.75 µs |

Notes:

- **Stress event** (`run_stress.sh`, `config_for_optimizer_stress.yaml`):
  a near-anode 0.6 MeV cluster carries almost no lifetime information —
  the −26 µs offset is a ~0.2σ draw from the σ_τ ≈ 110 µs floor, not an
  optimizer problem. Earlier runs that re-rolled noise per epoch/run
  (`config_for_optimizer_stress_chunk{1,2}.yaml`) landed at +105 µs with
  ±6 µs Adam wander — same distribution, noisier machinery. Segment
  bookkeeping for the event: `ev2_segments_note.md`.
- **Muon track** (`muon_long_track/`, selection details in its README):
  ~30× smaller σ_τ from the 100× charge and the long drift span.
- **Wide starts**: arms from 2.0/0.5 ms converge to the same minimum as the
  narrow starts (170 e−: minima agree to ~1 ns). Tripling the noise scales
  the offset ~linearly (−0.75 µs → −1.8 µs ≈ ×2.4, vs ×2.9 naive), i.e. the
  residual is pure noise projection, no optimizer pathology.
- **Arm extension**: a 500 µs journey exhausts Adam's step size before full
  convergence (~7 µs short after 2600 epochs). Resume the lagging arm at its
  final value with `nepoches_inc: 1` + `nepoches_dec: <n>` and the same seed
  (`muon_widestart_500/dec_extension/`), then merge trajectories with
  `concat_history.py`. The same seed makes this a true continuation.
  The 170 e− wide-start dec arm (ended at 0.99208) still awaits this
  treatment.

## Plotters

- `plot_lifetime_paper.py` — single-panel lifetime-vs-epoch paper figure
  from a `lifetime_fit_results.npz` (png + pdf).
- `muon_widestart_500/plot_full_history.py` — two panels from the
  concatenated history (`lifetime_fit_results_full.npz`): lifetime vs epoch
  and loss−L_min on a log axis (the MSE sits <0.1% above the σ² noise
  floor, so raw loss is flat; the log-excess shows 4 decades of
  convergence down to the float32 resolution of the loss).

## Practicalities

- GPU memory scales with segment count (autograd graph spans all chunks of
  an epoch): 38 segments ≈ 9 GB. Budget at export time with
  `make_muon_track.py --max-segments` (counts post-subdivision segments).
- Run scripts `cd` into their own directory first; logs and npz land there
  (`graph_opt.py` writes `lifetime_fit_results.npz` to the cwd). Do not
  overwrite existing results — new studies get new subdirectories.
- Noise scale context: white 170 e−/tick ≈ 1 ke− ENC over a 1.6–2 µs
  integration window (LArPix-scale). Open check before quoting absolute
  charges: the collection-pixel waveform integral is ~10× the
  recombination-corrected deposited charge — response normalization to be
  verified.
